# Ресурсы темы 3.4

## Датасеты

- **Pima Indians Diabetes** (чистая версия) и учебный `diabetes_leaky.csv` — материалы занятий: https://www.kaggle.com/datasets/uciml/pima-indians-diabetes-database
- **Heart Failure Prediction** (Kaggle) — для самостоятельного прогона через AutoML: https://www.kaggle.com/datasets/fedesoriano/heart-failure-prediction

## Инструменты

- Яндекс DataSphere (вариант А, ноутбуки-шаблоны): https://yandex.cloud/ru/services/datasphere
- Google Colab (вариант Б): https://colab.research.google.com/
- PyCaret — библиотека под капотом ноутбука-шаблона (заглянуть из любопытства, писать код не требуется): https://pycaret.org/
- H2O AutoML (вариант Б, демо): https://h2o.ai/platform/h2o-automl/
- Orange, дополнение Explain (SHAP-виджеты): https://orange3-explain.readthedocs.io/
