# Ресурсы темы 3.3

## Датасеты

- **Pima Indians Diabetes** (продолжаем работу с очищенной версией занятия 2): https://www.kaggle.com/datasets/uciml/pima-indians-diabetes-database
- **Stroke Prediction** (Kaggle) — полигон для разговора о дисбалансе классов и ловушке accuracy (событий ~5%): https://www.kaggle.com/datasets/fedesoriano/stroke-prediction-dataset
- `diabetes_leaky.csv` — учебный датасет с подсаженными дефектами, раздаётся преподавателем (инструкция по сборке — в [../../docs/instructor-guide.md](../../docs/instructor-guide.md))
