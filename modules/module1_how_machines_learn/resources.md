# Ресурсы темы 3.1

## Датасеты

- **Pima Indians Diabetes** — основной датасет темы (768 наблюдений, прогноз диабета): https://www.kaggle.com/datasets/uciml/pima-indians-diabetes-database
- **UCI Machine Learning Repository** — каталог классических медицинских датасетов (пригодится при выборе проекта): https://archive.ics.uci.edu/
- **PhysioNet** — физиологические сигналы и клинические базы, включая демо-версии реанимационных регистров: https://physionet.org/

## Инструменты

- Orange Data Mining — дистрибутив (вариант А и Б): https://orangedatamining.com/download/
- Каталог виджетов Orange с описаниями (File, Data Table, Test and Score и др.): https://orangedatamining.com/widget-catalog/
- Обучающие видео Orange (короткие ролики по каждому виджету): https://www.youtube.com/@OrangeDataMining
