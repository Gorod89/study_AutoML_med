# Чек-лист готовности к зачёту (Д3)

Пройдите список всей командой перед сдачей пакета. Полные требования — в [zachet.md](zachet.md).

## Постановка

- [ ] Клинический вопрос записан по шаблону: популяция → исход → момент прогноза → что изменится в тактике.
- [ ] Назван пользователь модели и сценарий применения (скрининг / приём / стационар).

## Данные

- [ ] Датасет открытый, лицензия проверена, версия/дата выгрузки зафиксированы.
- [ ] Словарь переменных составлен (имя, тип, единицы, доступность в момент прогноза).
- [ ] Есть ответ на вопрос «кого нет в данных» (смещение выборки).
- [ ] Пропуски, дубли, кодирование обработаны; каждый шаг — в протоколе решений.
- [ ] Проверки на утечки выполнены: признаки из будущего, технические поля (ID, даты), дубликаты пациентов.

## Модель и валидация

- [ ] Есть бейзлайн (логистическая регрессия) и минимум два алгоритма сравнения.
- [ ] Кросс-валидация — для сравнения моделей; отложенная выборка — «в сейфе» и использована один раз.
- [ ] При связанных наблюдениях разделение выполнено по пациентам.
- [ ] Финальные Se, Sp, PPV, NPV, AUC посчитаны на отложенной выборке.
- [ ] AUC выше 0.95 — проверено повторно на утечку (или объяснено).

## Порог и клиническая интерпретация

- [ ] Рабочий порог выбран и обоснован ценой FP/FN, а не оставлен 0.5 по умолчанию.
- [ ] PPV пересчитан под реалистичную распространённость сценария.

## Объяснимость и справедливость

- [ ] Глобальный SHAP построен и прокомментирован клинически.
- [ ] Разобраны 2 локальных объяснения (типичный и пограничный пациент).
- [ ] Метрики посчитаны по подгруппам (минимум два разреза), выводы сформулированы.

## Ограничения и оформление

- [ ] Раздел «Ограничения и риски» — не менее 5 конкретных пунктов.
- [ ] Зачётный пакет полон: паспорт, .ows, данные, протокол, слайды.
- [ ] Соседняя команда (или другой проверяющий) воспроизвела результаты по пакету.
- [ ] Пакет загружен в LMS за 48 часов до защиты.

## Защита и рецензия

- [ ] Доклад отрепетирован с таймером: 10 минут, говорят все.
- [ ] Каждый участник готов ответить по любому блоку (типовые вопросы прогнаны).
- [ ] Мини-рецензия сдана: 1–2 страницы, структура по TRIPOD+AI, вердикт о применимости.
- [ ] Нигде в материалах нет реальных данных пациентов.
